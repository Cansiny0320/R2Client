# R2Client 设计

> 历史方案：Web 部分已被[桌面专用设计](../specs/2026-11-08-r2client-desktop-only-design.md)取代。

R2Client 是独立实现的 MIT 开源 Cloudflare R2 管理器。Windows、macOS、Linux 使用 Electron，Web 和桌面共用 TypeScript/React 界面。参考产品的安装包和文档只用于核对能力；本项目不包含其源码、素材、账号或激活逻辑。

- 四端：多账户多桶、目录与虚拟列表、文件详情、索引和全桶搜索、预览及缩略图、所有文件和目录的批量操作、前后缀/序列/替换/正则重命名、属性编辑、传输与同步、对象统计、可核对的 SHA-256 去重、主题/缩放和中英日韩界面。
- 上传：选择、拖拽、目录、剪贴板、URL 与暂存；分片传输、可限并发、暂停、取消和恢复。续传根据服务端已存在的分片及内容检查决定可复用的分片。下载支持按对象身份校验、范围请求和续写。迁移文件先成功复制再删除；逐项报告失败。
- 桌面：隔离的 preload 和经过校验的 IPC；系统保护凭据；本地 FFmpeg 处理图片、音频和视频。支持本地目录增量同步及应用后台运行时的定时同步，保留磁盘空间和用户确认的边界。
- Web：浏览器本地签名、凭据只在会话内；配置桶 CORS 后直连 R2。URL 仅浏览器直读；不提供转码、服务端代抓、关掉浏览器后的后台同步；支持运行期间手动同步、浏览器允许时写入用户选择的目录。无 VPS，无中央对象索引。
- 分享：公共域名链接、S3 预签名 GET、QR 和复制格式。选配 Cloudflare Worker + D1 提供密码链接；创建、撤销受管理授权保护；服务加密保存短期单对象授权、盐化密码验证数据和到期时间，校验后流式下载。R2 凭据不上传。
- 发布：用 GitHub Actions 验证 Windows x64、macOS x64/arm64、Linux x64 构建，CI 产物不自动建 Release。公开仓库 Cansiny0320/R2Client。Web 与 Worker 提供自托管配置，当前任务不部署、不中转项目数据、不使用 VPS。
