# R2Client 桌面版专用构建

状态：已批准。此设计取代首版设计中的 Web 应用和部署部分。

R2Client 的 Windows、macOS、Linux 安装包直接构建 React 界面。Electron 仍通过 `r2app://local` 加载界面，并由原有 preload 调用本地引擎。保留应用 ID、用户数据目录、存储键、凭据加密和传输队列。连接有效时打开已选桶；旧的示例桶不参与选择。没有存储桶时展示欢迎页，再按账户、凭据、桶配置、公开访问和审查五步引导。保存成功后启动首次同步。无凭据的已有桶保留在列表中，允许重新连接。

删除浏览器驱动、OPFS、TanStack 路由、Web 部署和 CORS 示例，以及 Web 构建产物。可选密码分享服务独立保留。桌面本身直接访问 R2；不启用 VPS，不修改 R2 桶权限。

关键验收是全新配置能完成引导、已有配置能在实际安装版重启后继续使用、打包不依赖 Web 应用。现有原版保留。
