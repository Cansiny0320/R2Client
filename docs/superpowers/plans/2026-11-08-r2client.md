# R2Client 实施计划

> 历史方案：Web 部分已被[桌面专用设计](../specs/2026-11-08-r2client-desktop-only-design.md)取代。

1. 根目录建立 pnpm workspace、Vite+/TypeScript 检查和四个运行层；验证依赖锁定和干净安装。
2. packages/core 与 packages/s3：实现连接、对象列表与索引、批量管理、完整键名编码、任务状态、分片续传、SHA-256 和分享格式。以本地 S3 协议测试双跑小文件、分片失败及恢复、部分失败、前缀边界与特殊文件名。
3. apps/web 与 packages/ui：TanStack Start SPA；组件和交互覆盖桶、浏览、上传、传输、统计、扩展和设置；使用 IndexedDB 保存配置及任务元数据（不保存 R2 密钥）。用无头浏览器验证连接配置、演示数据及跨视图主流程。
4. apps/desktop：Electron main/preload、系统凭据、受限磁盘和媒体操作、FFmpeg、持久任务和定时同步；在本机无头验证可隔离的逻辑与打包。
5. apps/share：Cloudflare Worker、D1 migration、短期对象授权、密码防暴力尝试及撤销；使用本地 Workers 运行时或仿真测试过期、Range、密钥隔离、限流和撤销。
6. README、构建矩阵、CORS 及部署示例；运行 pnpm check、pnpm test、pnpm build、浏览器和本机桌面安装包验证。检查待提交清单，不包含凭据、解包原件和产物。通过后初始化 Git、提交并创建公开仓库，核验远端和构建矩阵结果。

风险：批量删除与对象替换具有真实后果；用隔离测试桶或模拟服务验证，展示明确计划、逐项失败和源对象保护。全桶扫描可能较贵，按需运行。磁盘写入限制在用户选定的根目录并防止路径穿越。回滚：本地可删除新项目之前先备份用户数据；Git 用 revert；Cloudflare 分享服务部署后可回退 Worker 版本，禁止自动修改 R2 生命周期或删除用户对象。当前仅授权创建公开仓库和推送项目，不发布云服务。
