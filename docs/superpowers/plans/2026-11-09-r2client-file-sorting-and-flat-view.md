# R2Client 文件排序和平铺实施计划

依据同日的文件排序和平铺设计。实现和验证使用当前分支和隔离测试数据。

## 文件工具栏排序

- 在 `packages/ui/src/files.tsx` 将排序从搜索弹窗移到工具栏，沿用工具栏和表单控件的样式。用现有排序逻辑扩展三个字段的双向排序，保持目录浏览时文件夹优先。排序先于 UI 分页，切换排序回到第一页。
- 更新 `tests/browser/workspace.spec.ts` 的工具栏断言。通过跨 R2 页的测试数据验证六种排序方向、默认排序、分页和搜索清除后的排序状态。

## 平铺当前路径

- 在 `packages/core/src/model.ts` 和 `packages/core/src/engine.ts` 扩展现有分页列举入口，默认使用原来的单层列举，平铺时传入递归选项。复用 `packages/s3/src/index.ts` 已有的递归能力和渲染层的分页循环。
- 在 `packages/ui/src/files.tsx` 接入平铺开关、相对路径和当前范围搜索。分别校验目录路径和视图模式，避免在切换时显示上一请求的结果。切换后清空关键词和选择，并返回第一页。列表展示使用相对路径，文件操作沿用原对象键。
- 在 `tests/transfer.test.ts` 验证 Engine 默认与递归列举的差异。在 `tests/browser/workspace.spec.ts` 验证根目录和子目录范围、跨页、同名文件、目录占位对象、切换视图、搜索、错误重试和文件操作的对象键。

## 验证与回滚

- 运行 `pnpm check`、`pnpm test`、`pnpm build` 和 `pnpm test:renderer`。构建会更新被 Git 忽略的 `apps/desktop/dist`，Playwright 会使用本地静态服务器和隔离的 R2 替身。
- 在大目录中，首屏等待当前范围列举完成后才显示完整排序结果。通过分页读取和现有失败重试处理网络异常，通过有效性检查避免旧请求覆盖新视图。
- 回滚时撤回本次文件列表界面、列举可选参数及对应测试的差异，再重新构建客户端。没有持久化数据迁移。
